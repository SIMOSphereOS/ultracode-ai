## Kontext / Context

**DE:** Welches Problem oder welche Kraft zwingt zu einer Entscheidung? Ist-Zustand,
Randbedingungen, betrachtete Alternativen (stichpunktartig, mit dem wichtigsten
Ablehnungsgrund je Alternative).
**EN:** Which problem or force requires a decision? Current state, constraints,
alternatives considered (bullet points, with the main rejection reason per alternative).

## Entscheidung / Decision

**DE:** Die getroffene Entscheidung in ein bis drei Sätzen, aktiv formuliert
(„Wir führen … ein", „Wir verwenden …"). Konkrete Pfade, Werkzeuge, Namen.
**EN:** The decision in one to three sentences, phrased actively
("We introduce …", "We use …"). Concrete paths, tools, names.

Name positive and negative consequences honestly.
