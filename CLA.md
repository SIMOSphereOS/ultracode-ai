## Signieren / How to sign

**DE:**

- **CLA-Assistant (empfohlen):** Beim ersten Pull/Merge Request kommentiert ein CLA-Bot und bittet um Zustimmung per Klick. Die Zustimmung wird pro GitHub-/GitLab-Account gespeichert und gilt für zukünftige Beiträge.
- **DCO-Sign-off (Alternative):** Bestätigen Sie den [Developer Certificate of Origin](https://developercertificate.org/) durch einen signierten Commit:
  ```bash
  git commit -s -m "feat: kurze beschreibung"
  ```
  Das fügt eine Zeile `Signed-off-by: Name <email>` hinzu. Ein reines DCO-Sign-off bestätigt die **Herkunft**; die weitergehende **Lizenzierungs-Rechteeinräumung** dieses CLA erfolgt über den CLA-Assistant bzw. eine separate Zustimmung.
- **Firmen-CLA:** Tragen Beitragende **im Auftrag eines Arbeitgebers** bei, benötigt SIMO zusätzlich ein von einer zeichnungsberechtigten Person unterschriebenes **Corporate CLA**. Kontakt: licensing@simosphereai.com.

**EN:**

- **CLA-Assistant (recommended):** On your first pull/merge request a CLA bot comments and asks you to consent with one click. Consent is stored per GitHub/GitLab account and applies to future contributions.
- **DCO sign-off (alternative):** Certify the [Developer Certificate of Origin](https://developercertificate.org/) with a signed commit:
  ```bash
  git commit -s -m "feat: short description"
  ```
  This adds a `Signed-off-by: Name <email>` line. A DCO sign-off alone certifies **provenance**; the broader **licensing grant** of this CLA is captured via the CLA-Assistant or separate consent.
- **Corporate CLA:** If you contribute **on behalf of an employer**, SIMO additionally requires a **Corporate CLA** signed by an authorized signatory. Contact: licensing@simosphereai.com *(placeholder address)*.
